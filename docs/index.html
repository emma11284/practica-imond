UNA ACLARACIÓN IMPORTANTE

Una visita no siempre es una persona distinta.

Un cliente identificado puede navegar varias veces. También puede haber visitas sin iniciar sesión.

Contamos clientes identificados distintos y sesiones anónimas como un indicador combinado de actividad. No podemos asegurar que cada sesión anónima pertenezca a una persona diferente.

04 · DASHBOARD WEB

La exploración

La página lee los datos preparados y permite recorrerlos mediante filtros.

Conocer el criterio de cálculo

SQL construye el modelo y los marts. Ticket, Usuarios y NPS se leen de resultados calculados para cada período.

La página selecciona esos resultados, suma importes aditivos de los marts diarios y dibuja los gráficos. No consulta RAW.

Las relaciones disponibles determinan qué filtros pueden aplicarse. No se atribuyen provincias ni productos a registros que no contienen esos datos.
